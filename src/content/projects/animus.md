A personal anime tracker that runs locally. There is no account and no cloud: the list is stored in a spreadsheet next to the app. The server uses only the Python standard library, and the Windows download bundles Python.

## Features

- Episode links for any streaming site, one per season, with a play button that opens the next episode.
- An Airing tab, plus covers, ratings and genres from AniList, cached on disk.
- Discover for the current season or any past or upcoming one, with one-click add.
- Recommendations shared with friends through a short code or a small file. Only thumbs-up picks are shared.
- A manga tracker with its own list, Discover and Stats.
- Import from MyAnimeList and Anime-Planet exports.
- Themes drawn from a show's cover, backups, and one-click updates from GitHub Releases with SHA-256 verification.
